# FLOW TAPE Studio Notes

AI音楽制作における創作ログ管理システム

## コンセプト

完成した作品だけでなく、

- 何を考えたか
- どのようなイメージを持ったか
- どのように改善したか
- どのような作品が生まれたか

という創作の進化を保存することを目的としています。

Notionの創作ノート機能と、GitHubのバージョン管理思想を取り入れた作品管理システムです。

---

## 主な機能

### プロジェクト管理

- 作品名
- 作成イメージ
- ジャンル
- 歌声
- 声質
- 制作状況

### 創作ログ管理

- プロンプト保存
- 良かったこと
- 改善したいこと
- 次回試したいこと

### Version管理

- Version1
- Version2
- Version3

ごとの履歴を保存

### 成果物管理

- Suno URL保存
- 採用／没管理
- 感想管理

---

## システムの特徴

FLOW TAPE Studio Notes は、

**「完成作品」ではなく、
「創作の進化」を保存するシステムです。**
